将首页替换为聚合四个内容板块的自用布局:

- 动态: 仅视频动态, 需要登录;
- 综合热门: 对应 `/v/popular/all` 的数据, 不做时间过滤;
- 每周必看: 默认最新一期, 可手动切期;
- 稍后再看: 纯列表 + 刷新, 需要登录.

请注意:

- 此功能与 `清爽首页`、`极简首页` 互斥, 请勿同时启用.
- 动态需要登录; 首次启用时只显示启用时间点之后发布的视频, 可能为空.
- 稍后再看不参与已读; 已读只在动态/热门/每周之间共享.
- 稍后再看板块不显示 VideoCard 的快捷添加; 其他板块保留.
- 点击模式下, 卡片左上角可手动标记已读, 右上角可固定; 已读后两个按钮仍显示, 标记按钮置灰, pin 可继续操作.
- 固定阻止点击/曝光自动标记; 已读后固定会让卡片继续留在列表并保持淡化, 取消固定后按已读展示规则消失; 不阻挡手动已读、全部标记已读和刷新.
- 固定按账号保存在本地, 最多 1000 条; 可在「聚合首页 → 固定记录」中清空.
